¡Bienvenido a SaguiOS-Extended v4!
==================================

SaguiOS-Extended (basado en SaguiOS, de Eli Rigobeli) es un sistema operativo pequeño, escrito desde cero por una IA,
para PC x86 de 32 bits. Se ejecuta entero en memoria: el pendrive de
arranque solo se lee una vez, cuando se enciende el ordenador.

Cómo usar el terminal
---------------------

El terminal es sagsh, un programa normal. Escribe un comando y pulsa Intro.
Cada comando tiene también un alias en portugués:

  ajuda              lista todos los comandos (ajuda <comando> explica uno)
  ls / listar        muestra los archivos de la carpeta actual
  cd / entrar        entra en una carpeta (cd .. sube una)
  cat / ver          muestra el contenido de un archivo
  echo / eco         escribe un texto (echo hola > tmp/a.txt lo guarda)
  cp, mv, rm         copia, mueve y borra archivos
  mkdir, rmdir       crea y borra carpetas
  wc / conta         cuenta líneas, palabras y letras
  ps / processos     muestra los programas en ejecución
  kill / matar       termina un programa
  mem, data, sobre   memoria, fecha y hora, y acerca del sistema
  contador 10 &      cuenta 10 segundos en segundo plano
  falha              provoca un error a propósito (solo muere el programa)
  limpar, reiniciar, sair

Trucos: comando > archivo, comando >> archivo, comando < archivo,
comando1 | comando2 (ej.: ls bin | conta), la flecha arriba repite
comandos, Tab completa nombres, Ctrl+C para un programa (en la ventana
Terminal).

El lenguaje del shell
---------------------

sagsh entiende lo esencial de sh/bash (ajuda sh lo resume):

  x=5; echo "x vale $x"            variables (export x: la ven los programas)
  ls /noexiste || echo fallo       && y || según el resultado ($? lo guarda)
  for f in /ejemplos/*.c; do echo $f; done
  if [ -d /tmp ]; then echo si; else echo no; fi
  n=$(ls /bin | conta); echo $((2 + 3 * 4))
  saluda() { echo "hola $1"; }; saluda Tito
  cat <<FIN                        here-doc: el texto hasta la línea FIN
  sagsh /ejemplos/hola.sh Ana      scripts (o un archivo que empiece por
                                   #!/bin/sh: /ejemplos/funciones.sh)

Si una línea queda abierta (comillas, if sin fi...), sagsh pide el resto
con "> ". El archivo /etc/sagshrc se lee al abrir el shell (alias, PS1...).

Programar en SaguiOS
--------------------

  cc /ejemplos/hola.c -o /tmp/hola    compila un programa en C
  /tmp/hola                           y ejecuta el ejecutable generado
  python                              abre MicroPython (Ctrl+D sale)
  python /ejemplos/hola.py            ejecuta un programa en Python

Archivos para leer
------------------

  sobre.txt              cómo se hizo el sistema
  historia/linux.txt     un poco de la historia de Minix, Linux y GNU
  historia/saguios.txt   el diario de este proyecto
  arte/sagui.txt         nuestra mascota

Los archivos que crees en /tmp se quedan en memoria y desaparecen al apagar.
Para guardarlos de verdad, usa un pendrive de datos (comandos montar y mount)
o la imagen con partición de datos: lo que guardes en /home se conserva.
