# 006 - Control de versiones con git

- **Estado:** hecha
- **Prioridad:** alta
- **Alta:** 2026-11-06

## Problema / motivación

La carpeta no es un repositorio git (se copió sin `.git`). Sin historial no se pueden revisar
ni deshacer cambios, y trabajar en paralelo (traducción, compilador, MicroPython) obliga a
usar copias del directorio.

## Propuesta

- `git init` y un primer commit con el estado original (antes de la traducción),
  recuperado de la copia `sagui-os-base`.
- Una rama por mejora, y fusionar `sagui-os-extras` como rama.

## Criterios de aceptación

- [x] Repositorio inicializado (rama `main`): un primer commit con el original y otro con
  la traducción, el teclado y SIMD
- [ ] Cada mejora futura en su propia rama o commit
- [ ] Integrar `sagui-os-extras` (compilador C y MicroPython) como rama
- [ ] Subirlo a un remoto (GitHub/GitLab) si se quiere compartir
