# Iconos usados en la biblioteca del SaguiOS (D135)

Todos estos iconos son del juego **Fluent UI System Icons** de Microsoft
(Copyright (c) 2020 Microsoft Corporation, licencia MIT), servido por Iconify.
El rasterizado a 16x16 y el paso a pixel art los hace `tools/gerar-icones.py`
de este proyecto; el resultado es `userland/libsagui/icones.c`.

El texto de la licencia está en `LICENSE` (en esta misma carpeta).

## Conjuntos usados

| Prefijo de Iconify | Qué es | |
| --- | --- | --- |
| `fluent-color` | Fluent UI System Color Icons: los iconos a color (con degradados), 199 iconos | https://icon-sets.iconify.design/fluent-color/ |
| `fluent` | Fluent UI System Icons: la variante monocroma (relleno sólido), de donde salen los iconos que el juego a color no trae | https://icon-sets.iconify.design/fluent/ |
