# H15. Pipes

**Fase:** 3

## Objetivo

pipe y duplicar, búfer en el kernel, bloqueo de lector y escritor, EOF.

## Criterio de aceptación

Dos procesos transfieren por pipe un texto mayor que el búfer sin pérdidas ni duplicados.

## Resultado

**Concluida.** Código en `kernel/fs/pipe.c` y `sis_pipe`/`sis_duplicar` en `kernel/fs/arquivos.c`; programas `userland/testes/pipe.c`, `gerador.c`, `consumidor.c`; decisión D015.

- `pipe(fds)` crea un búfer circular de 512 bytes en el kernel con dos extremos (descriptores); `duplicar(antigo, novo)` conecta un descriptor a otro archivo abierto.
- El lector se bloquea con el pipe vacío; el escritor se bloquea con el pipe lleno; fin de archivo cuando todos los escritores cierran; "pipe roto" sin lectores.
- Prueba `tests/h15_pipes.py` (programa `/testes/pipe`): un generador escribe 20.000 bytes en un pipe y el padre lo lee todo (157 lecturas, 0 bytes distintos, fin de archivo al final); en el otro sentido el padre escribe 20.000 bytes para un consumidor, que los comprueba byte a byte; escribir sin lector da error.
