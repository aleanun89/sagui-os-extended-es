# H01. Preparar el entorno

**Fase:** 1

## Objetivo

Instalar NASM, QEMU, ImageMagick, Python; validar el GCC freestanding; crear carpetas, git, status.md y dashboard.

## Criterio de aceptación

`make` se ejecuta sin errores con un objetivo vacío; el dashboard se abre en el navegador.

## Resultado

**Concluida.**

- Herramientas: NASM 2.16.01, GCC 13.3 (`-m32` freestanding, ver D001), QEMU 8.2.2, ImageMagick 6.9, Python 3, mtools.
- Estructura de carpetas de la sección 5 del PRD, repositorio git, `status.md`, `dashboard/`.
- `tools/status.py` mantiene `dashboard/status.json`, `status.js`, `status.md` y estas páginas.
- Prueba: `make vazio` imprime `SaguiOS: alvo vazio ok`; el JavaScript del panel se ejecutó en Node con un DOM simulado y dibujó todas las secciones sin errores.
